# CSCI417 - Stress Level Classifier (End-to-End with MLflow)

This project builds an **end-to-end machine learning pipeline** to classify student stress level from survey responses.

## Project Structure

```text
CSCI417/
├── Stress (1).csv
├── configs/
│   └── config.yaml
├── artifacts/
│   └── model/
├── mlruns/                     # generated by MLflow run
├── src/
│   └── stress_classifier/
│       ├── components/
│       │   ├── data_processing.py
│       │   ├── model_trainer.py
│       │   └── model_evaluation.py
│       ├── pipeline/
│       │   └── train_pipeline.py
│       └── utils/
│           └── common.py
├── main.py
├── requirements.txt
└── setup.py
```

## Rubric Mapping

- **Concept Understanding**: clear modular ML pipeline with config-driven design.
- **Dataset Preprocessing & Appropriateness**: train/test split and categorical preprocessing via one-hot encoding.
- **Algorithm Implementation**: RandomForest classifier in a reproducible pipeline.
- **Performance Evaluation & Comparison**: accuracy, precision, recall, and F1 logged.
- **Report & Presentation Ready**: MLflow tracking, artifact saving, and clean folder structure.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

## Run Training

```bash
python main.py
```

## Run MLflow UI

```bash
mlflow ui --backend-store-uri ./mlruns
```

Then open: `http://127.0.0.1:5000`

## Notes

- Target label: `Stress Label`
- All feature columns are treated as categorical in this baseline version.
- Trained model is saved to `artifacts/model/stress_model.joblib`.
