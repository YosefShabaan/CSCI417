# CSCI417 - Stress Level Classifier (End-to-End with MLflow + Easy Deployment)

This project builds an **end-to-end machine learning pipeline** to classify student stress level from survey responses and deploys it with a simple Streamlit app.

## Project Structure

```text
CSCI417/
├── Stress (1).csv
├── app.py                       # Streamlit deployment app
├── configs/
│   └── config.yaml
├── artifacts/
│   └── model/
├── mlruns/                      # generated by MLflow run
├── src/
│   └── stress_classifier/
│       ├── components/
│       │   ├── data_processing.py
│       │   ├── model_trainer.py
│       │   └── model_evaluation.py
│       ├── pipeline/
│       │   ├── train_pipeline.py
│       │   └── predict_pipeline.py
│       └── utils/
│           └── common.py
├── Dockerfile
├── .dockerignore
├── main.py
├── requirements.txt
└── setup.py
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install -e .
```

## 1) Train Model

```bash
python main.py
```

This will:
- train the model
- log experiment in MLflow
- save model to `artifacts/model/stress_model.joblib`

## 2) Run MLflow UI

```bash
mlflow ui --backend-store-uri ./mlruns
```

Open: `http://127.0.0.1:5000`

## 3) Easiest Deployment (Local Web App)

```bash
streamlit run app.py
```

Open: `http://localhost:8501`

## 4) Docker Deployment (Optional)

```bash
docker build -t stress-classifier .
docker run -p 8501:8501 stress-classifier
```

## Notes

- Target label: `Stress Label`
- Baseline: all input columns treated as categorical
- UI dropdown choices are generated from dataset values
